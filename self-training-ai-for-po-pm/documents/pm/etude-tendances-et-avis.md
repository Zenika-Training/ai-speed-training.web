# Étude de tendances et avis sur les applications hôtelières (document fictif)

> Document fictif — aucune donnée réelle. Tous les chiffres sont fictifs.
> Extraits rassemblés par Salomé pour la préparation du trimestre suivant.

## 1. Baromètre des applications hôtelières — édition de l'an dernier

Source : baromètre annuel d'un cabinet d'études (fictif), publié l'an dernier. Méthode : enquête en
ligne auprès de 800 voyageurs d'affaires, dans un seul pays.

| Résultat | Valeur |
|---|---|
| Voyageurs d'affaires interrogés qui veulent régler leur note sans passer au comptoir | 62 % |
| Voyageurs d'affaires interrogés qui ont déjà réglé une note depuis une application | 18 % |
| Voyageurs d'affaires interrogés qui citent la facture au nom de leur société comme un irritant | 41 % |

Un encadré du même baromètre, sur un échantillon séparé de familles (taille non précisée) : 51 % des
familles interrogées préfèrent un contact humain au moment du départ.

## 2. Avis agrégés sur les applications des concurrents — trimestre en cours

Source : synthèse fictive des avis publiés dans les magasins d'applications, faite par Salomé.

| Application | Ce qui revient le plus | Exemple d'avis |
|---|---|---|
| Concurrent A | Le départ dans l'application est apprécié ; la facture arrive parfois deux jours plus tard | « Pratique pour partir vite, mais j'attends encore ma facture. » |
| Concurrent B | La messagerie avec la réception est lente | « Trois heures pour une réponse sur un oreiller. » |
| Concurrent C | Pas d'aide quand le code d'arrivée ne fonctionne pas | « Bloqué devant la porte à 23 h, personne à appeler. » |

## 3. Ce que ces extraits ne disent pas

le baromètre.

5 règles pour piloter la chaîne

  1. Spécifier avant de générer : l'IA amplifie aussi les mauvaises décisions.
  2. Expliciter le métier dans le Context Nexus : l'agent n'a pas d'intuition.
  3. Donner à l'agent CI un diff riche en contexte : -U10, pas -U3.
  4. Graduer le merge : sur le Core Domain, validation humaine obligatoire.
  5. Passer par l'AI Gateway : voir l'équipe, pas sa session.

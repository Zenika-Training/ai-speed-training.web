Les objectifs de la journée

Avant le jour J, lisez la documentation du Context Nexus, à l'étape « Se projeter » du programme.

1Livré la v0.2

Quatre évolutions de CourtLoop : la durée de réservation, un calendrier accessible, l'heure du club, les traces et métriques. Une release taguée le soir.

2Passé chaque lot par les gates

De G1 à G4 : à chaque gate, la machine donne son avis et une personne décide, en 10 minutes au plus.

3Pratiqué le Nexus, chacun dans son rôle

Les profils techniques explorent puis construisent avec Claude Code ; les profils non techniques découpent puis définissent le besoin.

4Préparé la suite

Le besoin du responsable de club, passé en G1 l'après-midi, devient le prochain lot.

5Mesuré sa journée

Trois chiffres en rétro : les passages de gate, les NO-GO, le temps de décision.

    Installer l'environnement

    Une invitation, une ligne à coller dans un terminal, et le poste est prêt. Les profils non techniques s'arrêtent aux étapes 1, 2 et 5 : la webapp leur suffit. Le détail est dans la documentation du Context Nexus (procédure P3b).

    1. 1

      Accepter l'invitation. Ouvrez le lien remis par l'animateur, choisissez votre identifiant et votre mot de passe (12 caractères au moins). Votre rôle dans la squad est déjà fixé : il est défini à la construction de ce lien. La page Votre accès GitLab s'affiche.

    2. 2

      Copier vos accès GitLab, tout de suite. Rangez-les dans votre gestionnaire de mots de passe.

      La page ne les affiche qu'une seule fois.

      AccèsÀ quoi il sert
      Adressehttps://gitlab.34-155-130-81.sslip.io, le GitLab du hackathon
      Identifiantle même que sur le central
      Jeton personnel glpat-…git et API ; c'est lui que l'installeur et git clone demandent
      Mot de passeseulement pour vous connecter à GitLab dans le navigateur
    3. 3

      Installer votre poste. Copiez la ligne affichée sur la page et collez-la dans un terminal (macOS, Linux, WSL) :

      curl -fsSL 'https://<central>/api/v1/poste/i/<code>/install.sh' | sh

      Sous Windows, dépliez Sous Windows (PowerShell) sur la page. Le script vérifie le paquet, l'installe, branche Claude Code et vous demande votre jeton, qu'il range dans un fichier lisible par vous seul. Il propose ensuite le dépôt de votre équipe : Entrée suffit pour l'accepter. Pour cloner, il demande votre identifiant puis ce même jeton.

      La ligne est valable 15 minutes. Passé ce délai, ou si vous avez fermé la page, Installer mon poste dans la webapp en donne une autre.

    4. 4

      Sans l'installeur, s'il échoue : clonez le dépôt à la main, avec votre identifiant et votre jeton comme mot de passe.

      git clone https://gitlab.34-155-130-81.sslip.io/courtloop/courtloop-web.git
cd courtloop-web
    5. 5

      Continuer vers Context Nexus. Cochez J'ai copié mon jeton et mon mot de passe, puis Continuer vers Context Nexus.

Glossaire ​

Assistant ​

Le produit qu'on utilise au quotidien (ChatGPT, Copilot, Claude.ai, Gemini) : une interface posée sur un harness, autour d'un modèle.

Capacité ​

Quantité de travail que l'équipe peut prendre dans un sprint donné, compte tenu des absences.

Checkpoint ​

Question de contrôle à la fin d'un exercice. Ta réponse reste dans ce navigateur.

Connecteur ​

Dans Claude (Desktop ou claude.ai), le branchement d'un serveur MCP sur l'assistant : une fois connecté, l'assistant peut lire (et parfois écrire) dans l'outil, avec tes droits.

Context window ​

Tout ce que le modèle « voit » au moment de répondre : consignes, historique, pièces jointes, résultats des tools.

Cycle time ​

Durée écoulée entre le début du travail sur une story et sa fin.

Dérive de contexte ​

Session qui se dégrade quand la context window se remplit d'ajouts, de corrections et d'informations périmées ou contradictoires : elle reste crédible mais s'éloigne du besoin initial.

DoD (Definition of Done) ​

Liste de critères qu'un travail doit remplir pour être considéré comme terminé.

Grounding ​

Ancrer la réponse dans des sources vérifiables plutôt que dans la « mémoire » du modèle.

Hallucination ​

Réponse fausse mais présentée avec assurance et vraisemblance.

Harness ​

Tout le logiciel autour du modèle : consignes, mémoire, tools, enchaînement des étapes. Deux assistants sur le même modèle diffèrent par leur harness.

Human-in-the-loop ​

Un humain qualifié valide la sortie de l'IA avant qu'elle soit utilisée.

Instructions personnalisées / assistant personnalisé ​

Consignes enregistrées une fois et réappliquées : toujours (instructions personnalisées) ou dans un espace dédié (GPT, Projet Claude, agent Copilot).

Jeu de rôle ​

Répétition d'une conversation où l'IA joue un personnage (un manager pressé, un développeur sceptique…), pour s'y préparer.

LLM (Large Language Model) ​

Modèle entraîné sur d'énormes volumes de texte, qui génère une réponse en prédisant le mot suivant.

MCP (Model Context Protocol) ​

Standard pour brancher de nouveaux tools sur un assistant : applications et données de l'entreprise.

Médiane ​

Valeur du milieu quand on range les valeurs dans l'ordre : moins sensible qu'une moyenne à une valeur extrême.

PMS ​

Système de gestion de l'hôtel : réservations, état des chambres, note du client.

Product Backlog ​

Liste ordonnée de ce qui reste à faire sur le produit, sous la responsabilité du Product Owner.

Prompt ​

La demande envoyée au modèle, consignes comprises.

Recette ​

Vérification, avant la mise en service, que ce qui a été développé respecte les critères d'acceptation. L'environnement de recette sert à ces essais.

Sécurité psychologique ​

Le sentiment, dans une équipe, de pouvoir dire un blocage, un doute ou une erreur sans craindre d'être jugé.

Session ​

Une conversation ; elle accumule du contexte, utile ou parasite.

Skill ​

Savoir-faire emballé (consignes, modèles, exemples, parfois des scripts) que l'assistant charge à la demande, quand la tâche correspond. Plus léger que des instructions permanentes, partageable dans une équipe. Claude parle d'« Agent Skills » ; d'autres assistants ont des équivalents.

SMART (action) ​

Une action spécifique, mesurable, atteignable, pertinente et limitée dans le temps.

Sprint Backlog ​

Le Sprint Goal, les éléments retenus pour le sprint et le plan pour les livrer : il appartient aux développeurs.

Sprint Goal ​

L'objectif du sprint, en une phrase : la valeur visée. Il donne une boussole quand le plan change en cours de sprint.

Token ​

Morceau de mot traité par le modèle ; c'est aussi l'unité de facturation (≈ ¾ de mot en anglais).

Tools ​

Capacités que le modèle peut appeler pendant sa réponse : recherche web, calcul, lecture de fichiers, Jira, Figma… (tool calling).

Transcription ​

Texte produit automatiquement à partir de l'enregistrement d'une réunion. Elle peut contenir des trous et des erreurs.

User story ​

Description courte d'un besoin du point de vue de l'utilisateur : « En tant que…, je veux…, afin de… ».

Vélocité ​

Quantité de travail, en points, que l'équipe termine en moyenne par sprint.

WIP (work in progress) ​

Nombre de stories en cours en même temps.

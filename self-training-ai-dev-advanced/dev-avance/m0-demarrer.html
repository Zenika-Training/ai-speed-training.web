Le workshop se joue dans ton terminal

Dev Avancé

Industrialiser ton usage d'un agent de code

  • Tu utilises déjà Claude Code au quotidien : exploration, plan, revue, CLAUDE.md.
  • Quatre techniques pour passer à l'échelle d'une équipe : le contexte partagé (A), les MCP (B), les hooks (C), les subagents (D).
  • Claude Code joue le formateur, et toi tu restes la porte humaine entre chaque étape.

Ce site te sert de guide de démarrage. Le cours, lui, tient dans une archive à télécharger.

1. Vérifie ton poste, puis dézippe

Étape 1

Rien d'autre à installer

Le serveur MCP d'exercice (module B) se lance avec java, les hooks (module C) avec bash : ton poste de dev suffit.

Ton poste

  • ✓Claude Codeinstallé, accès ouvert
  • ✓Java 21+lance aussi le serveur MCP d'exercice
  • ✓Maven 3.9+mvn -v
  • ✓gitgit --version
  • ✓bash ou zshlance les hooks ; sous Windows, Git Bash
sh
claude --version && java -version && mvn -v && git --version

Tu gères tes versions avec SDKMAN! ou mise ? Le mise.toml de l'archive active Java 21 et Maven 3.9.

Dézippe hors de tout projet, jamais…

  • ✕Dans un projet qui a déjà un CLAUDE.mdClaude Code le chargerait aussi, et le parcours changerait.

2. Lance la session SUPPORT

Ouvre un premier terminal dans claude-code-workshop-adv/ et lance Claude Code en mode Manual : il te demandera ton accord avant de modifier un fichier ou de lancer une commande, même quand l'outil s'industrialise.

sh
claude --permission-mode default

Puis écris :

text
Lis le fichier CLAUDE-CODE-WORKSHOP-adv.md et démarre.

3. Ouvre TRAVAIL quand SUPPORT te le demande

Étape 3

Le projet des exercices

À l'étape 0.3, ouvre un second terminal, dans claude-code-workshop-adv/ lui aussi. La session TRAVAIL s'ouvre dans artefacts/orders-api, une API de commandes fictive, avec son serveur MCP d'exercice dans outils/incidents-mcp/.

sh
cd artefacts/orders-api
git init -q && git add -A && git commit -qm "Etat initial"
mvn -q test
claude --permission-mode default

Ce que tu dois voir

  • ✓Une à deux minutesle premier mvn -q test télécharge les dépendances, sans rien afficher
  • ✓Un commit initialpour voir ce que Claude Code modifie (git diff)
  • ✓manual mode ons'affiche sous la zone de saisie de TRAVAIL

4. Le déroulé, et tes commandes

Trois fois, SUPPORT te fait relancer TRAVAIL (/exit, puis claude --permission-mode default)

  • Un CLAUDE.md créémodule A
  • Un serveur MCP déclarémodule B, accepte « incidents » au relancement
  • Un dossier de subagentsmodule D

Ce qui est créé pendant une session n'est chargé qu'au lancement de la suivante.

Tes commandes dans SUPPORT

  • NEXTOKpasser à l'étape suivante
  • RÉPÈTEréafficher l'étape en cours
  • OÙ EN SUIS-JEvoir où tu en es
  • RECADREl'IA s'écarte : elle reprend son rôle
  • ALLER Caller à un module, après confirmation
  • ENGLISHFRANÇAISchanger de langue
  • INDICESOLUTIONTERMINÉpendant le quiz final

À la fin du module B, puis avant le quiz, SUPPORT te propose /clear suivi d'une phrase de reprise pour alléger la session. C'est facultatif.

5. Reprendre plus tard, et si quelque chose coince

Étape 5

Tu peux t'arrêter à la fin de chaque module

Pour reprendre, relance claude --permission-mode default dans claude-code-workshop-adv/, puis donne à SUPPORT la lettre du module où tu t'étais arrêté.

text
Lis le fichier CLAUDE-CODE-WORKSHOP-adv.md et va au module C.

Si quelque chose coince

  • mvn ou java introuvablereprends l'étape 1
  • Pas de « manual mode on »/exit, puis relance avec --permission-mode default
  • /mcp ne montre pas « incidents »vérifie .mcp.json dans orders-api, relance, accepte le serveur
  • /agents est vide/exit, puis relance ; .claude/agents/ n'est lu qu'au lancement
  • SUPPORT s'écarte du parcoursécris RECADRE
  • Tes plugins ou hooks perturbentajoute --setting-sources project,local
  • Quota, accès, outils autorisésdemande à ton référent

À retenir

  • SUPPORT guide
  • TRAVAIL exécute
  • Toi, tu tiens la porte humaine

Au quiz final, aucun prompt n'est fourni : tu construis ta stratégie avec ce que les modules t'ont appris. L'archive contient aussi le corrigé : le quiz n'entraîne ton œil que si tu le fais sans regarder.

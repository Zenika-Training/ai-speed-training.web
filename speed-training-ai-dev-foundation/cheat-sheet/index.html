Comprendre la machine, cadrer

L'agent ne devine pas : il prolonge ce qu'on lui donne. Le dev reste pilote.

Le modèle prédit, le harness agit

  • Le LLM prédit le token suivant : il produit du plausible, pas du vrai. Relancer donne une autre réponse.
  • Pas de mémoire : à chaque appel, le harness renvoie toute la session. Une erreur du tour 2 est relue à chaque tour.

On monte d'un niveau avec un filet : tests, commits, diff relu.

6 réflexes pour lundi matin

  1. Vérifier : tests, typage et revue restent les garde-fous.
  2. Faire valider la demande et le plan avant le code.
  3. Rewind : corriger l'entrée et relancer, au lieu d'empiler.
  4. Une tâche, une session : ce qui traîne pollue.
  5. Relire le diff : un commit par étape, un humain avant le merge.
  6. La consigne qu'on répète devient une skill.

2 règles d'or

1. Outils validés, jamais de secretL'enverriez-vous par email à un inconnu ?

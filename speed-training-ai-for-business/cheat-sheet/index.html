Comprendre l'IA et bien lui demander

L'IA ne devine pas : elle prolonge ce qu'on lui donne.

Comment ça marche

  • Un LLM prédit la suite, token après token : du plausible, pas du vrai.
  • Chaque relance donne une autre réponse : une proposition, pas une vérité.
  • Pas de mémoire : toute la conversation est renvoyée à chaque message.

Assistant, harness, agent

L'assistant (ChatGPT, Copilot…) entoure le modèle d'un harness : consignes, mémoire, skills et tools (web, calcul, MCP).

Une bonne demande

Tu es [rôle], tu travailles sur [sujet].
Produis [livrable], au format [structure].
Règles : [cible, contraintes].
À éviter : [ce qu'il ne faut pas inventer].
Exemple : [un exemple du résultat attendu].

Un exemple vaut mieux qu'une longue description (few-shot).

Ses limites

  • Elle hallucine → vérifier les sources.
  • Elle amplifie vos données → regarder ce qu'on lui donne.
  • Elle ne remplace pas l'humain → garder l'humain au contact.

Capitaliser

  • Instructions personnalisées : toujours chargées.
  • Assistant personnalisé : un espace dédié.
  • Skill : chargé à la demande.
  • Avant de fermer, extraire décisions, risques et actions.

7 réflexes pour lundi matin

  1. Relancer avant de faire confiance.
  2. Les 4 ingrédients, puis une skill d'équipe.
  3. Demander une structure, puis le livrable.
  4. Repartir proprement quand ça dérive.
  5. Extraire et relire avant de fermer.
  6. Discovery : faits, lo-fi, vrais utilisateurs.
  7. Rien de sensible hors des versions entreprise, un humain valide.

Le PRD en une page

Problème · objectif mesurable · user story · périmètre · hypothèse · critère de succès

L'IA rédige le premier jet, l'équipe arbitre.

Prototyper, tester

  • Lo-fi d'abord, hi-fi ensuite.
  • Un prototype n'est pas un produit.
  • Observer de vrais utilisateurs, sans les aider.

2 règles d'or

1. Données sensibles : versions entreprise uniquementL'enverriez-vous par email à un inconnu ?
2. Un humain valide avant d'agirQui signe si c'est faux ?

Risques à connaître

  • Hallucination → relire, vérifier les sources.
  • Prompt injection → limiter les accès des agents.
  • Coûts → plafonds de dépense.

Consommer moins

  • 1 tâche = 1 session.
  • Une demande précise, une réponse concise.
  • Couper les connecteurs inutiles.

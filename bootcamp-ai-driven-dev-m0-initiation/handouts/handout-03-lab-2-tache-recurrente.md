# Handout — Lab 2 : automatiser une tâche récurrente

**Bootcamp AI-Driven Development · Module 0 · Zenika · support d'exercice**

Lab optionnel (~25 min) : transformer une tâche faite « à la main » chaque semaine en un Project ou une Skill réutilisable en 30 secondes.

## Étapes

1. **Choisir une tâche récurrente** : CR de réunion, relance client, brief offre, réponse candidat…
2. **Créer un Project / une Skill** dédié, avec un nom clair.
3. **Rédiger les instructions** : destinataire, ton, format de sortie, quoi éviter.
4. **Ajouter 2-3 exemples** en pièces jointes, ce qui fait passer de « correct » à « on dirait vous ».
5. **Tester sur un cas réel** et affiner selon ce qui manque ou dérape.

> **Règle d'or** : pas de données client confidentielles sans validation DSI, données anonymisées ou cas internes.

## Project ou Skill ?

|            | Project                                          | Skill                                                       |
| ---------- | ------------------------------------------------ | ----------------------------------------------------------- |
| Porte      | un **contexte**                                  | une **compétence** reproductible                            |
| Exemple    | « tout sur le client X »                         | « comment rédiger un CR chez nous »                         |
| Contenu    | documents de référence, instructions, historique | un `SKILL.md` (mode d'emploi) + des fichiers de support     |
| Chargement | quand on travaille dans le Project               | **automatiquement**, quand la Skill correspond à la demande |
| Partage    | au sein d'une Team Anthropic                     | au sein d'une Team Anthropic, comme un Project              |

Les deux se combinent.

## Structure minimale d'une Skill

* un **nom** + une **description** (quand l'activer) ;
* un `SKILL.md` (étapes, règles, pièges) ;
* en option des templates / checklists.

Pour la créer : demandez à Claude « je veux créer une nouvelle skill », ou passez par le menu **Customize**.

```text
Je veux créer une nouvelle skill.
```

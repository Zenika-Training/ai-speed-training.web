# Handout — Lab 3 : prendre en main Cowork

**Bootcamp AI-Driven Development · Module 0 · Zenika · support d'exercice**

Lab optionnel (~25 min) : déléguer à Cowork la préparation d'un livrable à partir de fichiers dispersés sur votre poste.

## Rappel : Claude Cowork

**Cowork** (beta, research preview) est un agent Claude qui tourne sur votre poste avec un accès contrôlé à un dossier local et au navigateur. Pensé pour les profils non techniques : tout en langage naturel.

* Lire et organiser les fichiers d'un dossier (nommer, ranger, archiver).
* Extraire du contenu d'un PDF, d'une image, d'un fichier Office.
* Créer des documents Word, Excel, PowerPoint à partir d'un brief.
* Exécuter une **Skill** sur vos données.
* Se connecter à vos outils (Slack, Drive, GitHub…) via MCP.

Différence avec le chat : Cowork a les mains dans vos fichiers et vos applis ; le chat se limite aux pièces jointes uploadées.

## Étapes

1. **Préparer un dossier dédié** (ex. `~/bootcamp-lab`) avec 4-5 fichiers réels non confidentiels.
2. **Ouvrir Cowork** et sélectionner ce dossier comme espace de travail.
3. **Donner une mission** :

```text
Lis tous les fichiers, résume les points clés dans un Word,
et range les fichiers par date.
```

4. **Observer** Cowork lire, demander confirmation, produire, et corriger au fil de l'eau.
5. **Itérer** :

```text
Même synthèse en slides.
```

```text
Extrais les actions dans un Excel.
```

> **Règle d'or** : isoler un dossier dédié, relire chaque modification, pas de dossier client confidentiel sans validation DSI.

> **Astuce** : faites créer par Claude les documents d'une fausse entreprise (fiche produit, facture, mails, slides).

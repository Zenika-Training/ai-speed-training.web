Glossaire ​

Agent ​

Modèle qui enchaîne lui-même des actions avec des tools, en boucle, jusqu'à atteindre un objectif : c'est la boucle agentique (modèle + tools + boucle + objectif, que le harness fait tourner). Les éditeurs utilisent aussi « agent » pour de simples assistants personnalisés.

Agent de code ​

Agent qui lit, modifie et exécute du code dans un dépôt (Copilot, Claude Code, Codex, Cursor…).

Boucle agentique ​

Le cycle demande → le modèle choisit un tool → le harness l'exécute → le résultat entre dans le contexte → on recommence si besoin.

Compaction ​

Résumé automatique ou demandé de la session pour libérer de la context window.

Context rot ​

Dégradation des réponses quand la context window se remplit d'ajouts, de corrections et d'informations périmées ou contradictoires : la session reste crédible mais s'éloigne du besoin initial.

Context window ​

Tout ce que le modèle « voit » au moment de répondre : consignes, historique, pièces jointes, résultats des tools.

Harness ​

Tout le logiciel autour du modèle : consignes, mémoire, tools, enchaînement des étapes. Deux assistants sur le même modèle diffèrent par leur harness.

Hook ​

Action déterministe déclenchée par le harness à un moment précis (avant une commande, après une édition), quoi que dise le modèle.

Human-in-the-loop ​

Un humain qualifié valide la sortie de l'IA avant qu'elle soit utilisée.

Instructions projet ​

Fichier versionné dans le dépôt, chargé à chaque session : conventions, commandes, pièges (AGENTS.md, CLAUDE.md pour Claude Code). C'est l'équivalent dev des instructions personnalisées.

MCP (Model Context Protocol) ​

Standard pour brancher de nouveaux tools sur un assistant : applications et données de l'entreprise.

Permissions ​

Les actions autorisées à l'agent (lire, écrire, lancer une commande, accéder au réseau).

Plan d'exécution ​

Liste d'étapes vérifiables que l'agent propose avant de coder, et que le dev corrige avant de le laisser faire.

Session ​

Une conversation ; elle accumule du contexte, utile ou parasite.

Skill ​

Savoir-faire emballé (consignes, modèles, exemples, parfois des scripts) que l'assistant charge à la demande, quand la tâche correspond. Plus léger que des instructions permanentes, partageable dans une équipe. Claude parle d'« Agent Skills » ; d'autres assistants ont des équivalents.

Subagent ​

Agent lancé par l'agent principal pour une mission étroite, dans sa propre context window : il ne renvoie qu'un résultat court, et la session principale reste légère.

Token ​

Morceau de mot traité par le modèle ; c'est aussi l'unité de facturation (≈ ¾ de mot en anglais).

Tools ​

Capacités que le modèle peut appeler pendant sa réponse : recherche web, calcul, lecture de fichiers, Jira, Figma… (tool calling).

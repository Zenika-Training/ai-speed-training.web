Développeur IA — Foundation

En autonomie, pour les devs qui découvrent un agent de code. Environ 2 h 25, en dix modules courts sur une petite API Java fictive : explorer un projet, décrire l'objectif, planifier avant de coder, tenir le contexte, faire relire, écrire les instructions projet, déléguer à des subagents, ajouter skills, MCP et hooks. Le cours se joue dans ton terminal : Claude Code te guide pas à pas, et toi tu gardes la main sur chaque modification.

Comment ça marche

  1. Télécharge le workshop (une archive zip) depuis le guide de démarrage, et dézippe-la hors de tout projet.
  2. Lance deux sessions Claude Code : SUPPORT te guide, TRAVAIL fait les exercices dans le projet.
  3. Avance à ton rythme avec NEXT : chaque module se fait seul, et tu peux t'arrêter puis reprendre plus tard.

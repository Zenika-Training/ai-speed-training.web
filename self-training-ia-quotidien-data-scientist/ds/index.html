L'IA dans le quotidien du Data Scientist

Pour les data scientists en poste. Tu travailles sur le churn du programme de fidélité de Lanterne en quatre chapitres : cadrer (traduire la question métier), modéliser (explorer, préparer les variables sans fuite, comparer à une baseline), l'IA générative (évaluer un assistant RAG), industrialiser et restituer (passer le modèle en production, suivre la dérive, présenter au comité).

Prérequis : Être data scientist en poste (statistiques, Python, scikit-learn). Le kit facultatif demande uv ; sans lui, les sorties des notebooks sont dans les documents.
